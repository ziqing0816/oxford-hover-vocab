Oxford 划词助手——安装与使用
================================

一、安装

1. 把整个文件夹解压到任意位置。
2. 双击 setup.bat。
3. 如果提示找不到 Python，请安装：
   https://www.python.org/downloads/
   安装时勾选 Add Python to PATH。
4. 安装完成后，桌面会出现“Oxford 划词助手”和“生词复习”。

二、查词

按住 Ctrl，将鼠标移动到任意界面的英文单词上，停留约半秒。

- 连续按两次 Esc：结束
- Ctrl+Alt+H：暂停或恢复
- Ctrl+Alt+Q：结束

程序会先显示本地简体中文释义；配置 Oxford 官方 API 后，还会在后台补充英英释义、同义词和例句。

三、生词与复习

- 查到的单词会自动保存到本机 vocabulary.db。
- 双击 review-vocab.bat：打开复习卡片。
- 双击 export-vocab.bat：导出 Markdown 和 CSV 复习文档。

四、隐私

- 截图只交给 Windows 本地 OCR，不保存、不上传。
- 启用 Oxford 后，只发送被查询的英文单词。
- 原句、生词和复习记录只保存在本机。
- 不要把 Oxford App ID 或 App Key 写进项目文件或发给别人。
- debug 模式可能把屏幕文字写入日志，平时请保持关闭。

五、出问题时

- 双击 run.bat 查看启动信息。
- 双击 make-shortcut.bat 重建桌面快捷方式。
- 完整说明请查看 README.md。
